Diccionario Git Interactivo

git init

Inicializa un nuevo repositorio local en la carpeta actual.

git commit

Guarda la captura de los cambios preparados en el historial.

git clone

Descarga una copia exacta de un repositorio remoto.

git add

Prepara los cambios (staging) para ser incluidos en el próximo commit.

git branch

Lista, crea o elimina ramas en tu repositorio local.

git checkout

Te permite saltar de una rama a otra para trabajar en diferentes flujos.

git merge

Combina el historial y los cambios de una rama dentro de tu rama activa.
